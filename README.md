# smp_site_my_server
It is the site for my SMP site, which shows custom weapon and crafts for this weapon.


Description:

This website showcases custom weapons created for my SMP server. If you click on a weapon, you can view its crafting recipe and description. The site is in Russian. 

How to go to the website:

1. download the zip file.
2. open source.txt or SMP site.
